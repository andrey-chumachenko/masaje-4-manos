## Notas de uso

1. **Consistencia visual**: Usar el mismo seed/estilo base para mantener coherencia entre las fotos.
2. **Palette de colores**: Mantener tonos crema (#FAF6F0), dorado suave (#C9A96E), verde salvia (#8B9D77).
3. **Dimensiones recomendadas**:
   - Hero / Banner: 16:9 (1920x1080)
   - Cuadradas (grid galeria): 1:1 (1080x1080)
   - Vertical (retrato): 4:5 (1080x1350)
4. **Resolucion**: Generar a la maxima resolucion posible, minimo 2x para pantallas retina.
5. **Post-procesamiento**: Aplicar un filtro suave y calido uniforme a todas las imagenes para mantener la cohesion visual del sitio.
